DisneyConnect.com

This is a (bare-bones) recreation of the defunct site that generated working cheat codes for the following games:
  • Phineas and Ferb: Across the 2nd Dimension DS
  • Cars 2 DS
If you know of any other disney games that use this code format, let me know and i'll add them to this site.

From the title screen, tap Code Redemption, then Redeem Code Offline. (In Cars 2, this is under Extras.)
The game will give you a code to enter here, then the site will give you codes to enter into the game. (And they work!)

The code will be different depending on which game AND which DS you're playing on.
Make sure you type your code in ALL CAPS, all 13 characters, and only uses these characters: 012345689ACEFHKMPRTWXY
